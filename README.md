# againstAI-scarf-patterns

Two separate projects.

## `adversarial-knit-lab/`

A browser studio for designing reproducible colourwork knitting charts and
measuring them against a computer-vision model you load yourself. TypeScript,
React, Vite; deploys as a static site to GitHub Pages.

See [`adversarial-knit-lab/README.md`](adversarial-knit-lab/README.md).

No pattern it produces is known to defeat any computer-vision system.

## `antiAIscarf-generator/`

The original single-file study: a dependency-free two-colour pattern generator
in three files (`index.html`, `style.css`, `generator.js`). Open `index.html`
directly. Unchanged.

## `research/`

Optional local Python companion to the knit lab. The website does not need it.
See [`research/README.md`](research/README.md).
